# Deep-Learning--02

Welcome to the **Deep-Learning--02** repository! This project serves as a focused learning resource dedicated to understanding, building, and analyzing **Convolutional Neural Networks (CNNs)** for computer vision and image processing tasks.

## 📁 Repository Structure & Contents

This repository contains curated study materials and structural concept guides covering CNN architectures:

*   **30-33 CNN.pdf** & **30-38 CNN.pdf** – Comprehensive theoretical notes mapping out core CNN layers, operations, and advanced structural topics.
*   **CNN notes.pdf** – A detailed reference guide highlighting foundational concepts like feature extraction, kernels, pooling, and strides.

## 🧠 Core Topics Covered

By going through these documents, you will learn about:
*   **Convolutional Layers:** How filters/kernels extract spatial features (edges, textures, shapes) from input images.
*   **Pooling Layers:** Techniques like Max Pooling and Average Pooling used to reduce spatial dimensions and lower computational load.
*   **Padding & Strides:** Controlling the spatial size of output feature maps.
*   **Fully Connected Layers:** Flattening feature maps to make final classifications.
*   **Popular Architectures:** Theoretical insights into classic networks (e.g., LeNet, AlexNet, VGG).
